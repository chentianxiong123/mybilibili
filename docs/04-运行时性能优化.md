# 运行时性能优化

## 1. API 缓存策略

### 内存缓存

对公开只读的 GET 接口启用 30 秒 TTL 内存缓存，减少重复请求。

```typescript
// api/client.ts
const cache = new Map<string, { data: any; timestamp: number }>()

// 请求拦截器：命中缓存直接返回
requestInterceptor: (config) => {
  if (config.method === 'get' && CACHE_PATHS.includes(config.url)) {
    const cached = cache.get(config.url)
    if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
      return Promise.reject({ __CACHED: true, data: cached.data })
    }
  }
  return config
}

// 响应拦截器：存储缓存
responseInterceptor: (response) => {
  if (response.config.method === 'get' && CACHE_PATHS.includes(response.config.url)) {
    cache.set(response.config.url, {
      data: response.data,
      timestamp: Date.now()
    })
  }
  return response
}
```

**缓存路径：** `/category`、`/manuscript/recommended`、`/manuscript/hot`

**写操作自动清除：** 非 GET 请求自动清除对应前缀的缓存，保证数据一致性。

### 缓存策略对比

| 策略 | 适用场景 | TTL | 更新方式 |
|------|---------|-----|---------|
| 内存缓存 | 分类列表、推荐列表 | 30s | 写操作自动清除 |
| PWA 缓存 | 静态资源（JS/CSS/图片） | 永久 | 版本更新时替换 |
| HTTP 缓存 | 图片、视频封面 | 7天 | Cache-Control 控制 |

## 2. 路由预取

### 实现原理

用户 hover 导航链接时，提前加载目标路由的 chunk，减少页面切换等待时间。

```typescript
// composables/usePrefetch.ts
export function usePrefetch() {
  const router = useRouter()

  const prefetch = (routeName: string) => {
    const route = router.resolve({ name: routeName })
    const component = route.matched[0]?.components?.default
    if (typeof component === 'function') {
      component() // 触发动态 import，预加载 chunk
    }
  }

  return { prefetch }
}
```

### 挂载位置

| 组件 | 预取路由 |
|------|---------|
| AppHeader | 首页、直播 |
| HeaderActions | 收藏、历史、动态、创作中心 |
| CategoryTabs | 动态、热门、各分类 |
| UserMenu | 个人中心、投稿管理 |

### 收益

- 用户 hover 到点击之间有 ~200ms 时间窗口，足够预加载 chunk
- 页面切换时 chunk 已缓存，用户无感知等待

## 3. 虚拟滚动

使用 `@tanstack/vue-virtual` 实现长列表虚拟滚动，只渲染可视区域的 DOM 节点。

```vue
<template>
  <div ref="parentRef" class="list-container">
    <div :style="{ height: `${totalSize}px` }">
      <div v-for="item in virtualItems" :key="item.key">
        <VideoCard :video="videos[item.index]" />
      </div>
    </div>
  </div>
</template>
```

**适用场景：** 视频列表、动态流、评论列表、消息列表

## 5. 性能监控建议

| 指标 | 采集方式 | 目标值 |
|------|---------|--------|
| LCP | PerformanceObserver | < 2.5s |
| FID/INP | PerformanceObserver | < 100ms |
| CLS | PerformanceObserver | < 0.1 |
| 首屏 JS 体积 | 构建时测量 | < 100K gzip |
| API 响应时间 | Axios 拦截器 | < 200ms |

## 原则

- **缓存一切可以缓存的数据**，但要有合理的过期策略
- **预取用户即将需要的内容**，但不要过度预取浪费带宽
- **虚拟渲染长列表**，保持 DOM 节点数可控
- **监控驱动优化**，不要盲目优化没有瓶颈的地方
