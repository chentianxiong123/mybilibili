# 首屏体积优化实战

## 背景

mybilibili-nuxt 是一个基于 Vite 6 + Vue 3.5 的 SPA 项目，使用 Element Plus 2.x 作为 UI 组件库。首屏体积是用户体验的关键指标，直接影响 LCP 和用户留存。

## 优化目标

将首屏加载体积从 450K+ 压缩到 170K gzip 以内。

## 优化前状态

| 指标 | 数值 |
|------|------|
| 项目文件数 | 216（140 Vue + 76 TS） |
| 路由数 | 44 条，全部懒加载 |
| 首屏 JS | 170K gzip |
| 首屏 CSS | 14K gzip |
| 总 JS | 3.0 MB |
| 总 CSS | 614 KB |
| 部署方式 | Nginx → 静态文件 → Go API |

## 已完成的优化清单

| 优化项 | 说明 |
|--------|------|
| Element Plus 按需加载 | `unplugin-vue-components` + `unplugin-auto-import` |
| Element Plus 2.7.5 → 2.14.4 | 最新版本 |
| LightningCSS CSS 压缩 | `build.cssMinify: 'lightningcss'` |
| Brotli 预压缩 | `vite-plugin-compression`，生成 `.br` 文件 |
| 视频页动态加载 | hls.js (525K) + artplayer (142K) 按需加载 |
| API 缓存 | 公开 GET 接口 30s 内存缓存 |
| 路由 hover 预取 | `usePrefetch` composable |
| TS strict 部分开启 | `noUnusedLocals` + `noFallthroughCasesInSwitch` |
| Traefik Brotli/Gzip | 部署层压缩中间件 |

## 优化措施

### 1. 路由懒加载

所有 44 条路由均使用动态 `import()` 实现懒加载，确保每个路由页面只在访问时加载。

```typescript
// 优化前：静态导入
import HomeView from '../views/web/HomeView.vue'

// 优化后：动态导入
const HomeView = () => import('../views/web/HomeView.vue')
```

### 2. 第三方库动态导入

将大型第三方库从静态导入改为按需加载，仅在用户实际使用时才下载。

```typescript
// 优化前：静态导入 hls.js（525K）
import Hls from 'hls.js'

// 优化后：动态导入
const initPlayer = async () => {
  const Hls = await import('hls.js')
  // 初始化播放器
}
```

| 库 | 大小 | 优化方式 |
|----|------|---------|
| hls.js | 525K | 仅在有 m3u8 且无原生 HLS 支持时加载 |
| artplayer-plugin-danmuku | 55K | 仅播放弹幕视频时加载 |
| echarts | 524K | 独立 chunk，仅访问数据页面时加载 |

### 3. Vendor Chunk 拆分

通过 `manualChunks` 将稳定的第三方库拆分为独立 chunk，利用浏览器缓存。

```typescript
// vite.config.ts
manualChunks: {
  'vendor-vue': ['vue', 'vue-router', 'pinia'],
  'vendor-charts': ['echarts'],
  'vendor-utils': ['axios']
}
```

### 4. 结果对比

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 首屏 JS | 450K+ | 170K gzip |
| 视频页 | 628K 一次性加载 | 118K + 142K 按需 |
| hls.js | 入口打包 | 仅 m3u8 场景加载 |
| 首屏 CSS | 98K | 14K gzip |

### 5. 核心原则

- **衡量优先**：每次优化前后对比实际体积变化
- **用户视角**：只加载用户当前需要的代码
- **缓存友好**：稳定的第三方库拆为独立 chunk，利用 HTTP 缓存
- **渐进增强**：基础功能立即可用，高级功能按需加载
