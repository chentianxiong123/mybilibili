## P0：一键跑通全链路（建议立即做）

### 目标
```text
docker compose up → 注册 → 登录 → 发稿 → 看视频 → 评论 → 点赞 → 收藏 → 关注 → 动态流
```

### 任务清单

| # | 任务 | 说明 |
|---|------|------|
| 1 | Go 后端 Dockerfile | 多阶段构建，最终镜像 ~20MB，含 `cmd/core` + `cmd/media` |
| 2 | Web 前端 Dockerfile | `mybilibili-web-ts` 构建为 Nginx 静态镜像 |
| 3 | docker-compose.yml | PG(pgvector) + 后端 + Web 前端 + Traefik |
| 4 | 种子数据脚本 | 分类、测试用户、示例稿件/视频 |
| 5 | 健康检查端点 | `GET /api/v1/health` 返回 DB/MQ/Storage 状态 |
| 6 | 一键启动脚本 | `make up` 或 `./start.sh` |

### 验收标准
```bash
docker compose up -d
curl http://localhost:8080/api/v1/health          # → {"status":"ok"}
curl http://localhost:8080/api/v1/category          # → 返回分类列表
curl http://localhost:8080/api/v1/manuscript/hot    # → 返回热门稿件
```

## P1：补微服务已有功能模块

按实现成本从低到高排列：

| # | 模块 | 成本 | 说明 |
|---|------|------|------|
| 1 | Banner 管理 | 低 | 4 张表 + 5 个 CRUD 路由，可复用 admin 模式 |
| 2 | 推荐配置 | 低 | 1 张表 + get/set/reset 路由，redis 缓存 |
| 3 | 分片上传 | 中 | 已有 upload_sessions 表，需补 create/uploadChunk/complete/cancel |
| 4 | 存储迁移 | 中 | 迁移本地文件到 S3/MinIO，后台异步任务 |
| 5 | 音频提取 | 中 | 复用 FFmpeg Worker，提取音频流 |
| 6 | AI 用量统计 | 中 | 已有 ai_usage_logs 表，补记录+查询接口 |
| 7 | 连麦 (Linkmic) | 高 | WebRTC 信令 + SRS 集成，需要独立信令服务 |
| 8 | 会议室 | 高 | WebSocket 信令 + 音视频转发，需独立信令服务 |
| 9 | 工作室导出 | 高 | 云端渲染引擎 + 时间线编排，复杂业务逻辑 |
