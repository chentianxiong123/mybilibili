## 阶段二：AI 侧车接入

### 现状
AI 摘要/审核/客服代码结构完整，但后端 `memoryCaller` 返回 "not implemented"。

### 接入方式
```
Go 单体 ──HTTP──▶ AI 侧车（独立进程）
                  ├── /api/v1/ai/summary    → LLM 生成摘要
                  ├── /api/v1/ai/moderate   → 内容审核
                  └── /api/v1/ai/chat       → 客服对话
```

### 侧车实现
- 语言：Go（与主进程同语言栈，编译为独立二进制）
- 模型：Ollama（本地运行 deepseek 等开源模型）或直接调 OpenAI 兼容 API
- 不引入 Python / Spring Native

### 已就绪的 AI 基础设施
| 组件 | 状态 |
|------|------|
| `ai_summary.go` SummaryService / ReviewService / CustomerService | ✅ 接口定义完整 |
| `ai_repository.go` 技能/会话/配置/用量 CRUD | ✅ 全量实现 |
| `ai_http_handler.go` 审核/客服 HTTP 路由 | ✅ 路由注册 |
| `ai_handler.go` 管理后台路由 | ✅ 路由注册 |
| `pgvector` 向量索引 | ✅ 已启用 |
| 仅缺 LLM 后端接入 | ⏸ |
