# old/ — 历史项目快照（只读参考）

本目录是项目演化过程中**早期版本**的完整源码快照，按提交时间归档：

| 子目录 | 内容 |
|---|---|
| `admin/` | 早期管理后台版本 |
| `java/` | Java 原型 |
| `microservices/` | 早期微服务架构尝试 |
| `obs-plugin/` | OBS 直播插件原型 |
| `springboot3/` | Spring Boot 3 重写版本 |
| `web/` | 早期 Vue2/3 单体前端 |

## ⚠️ 不要修改

- 这些是**历史参考实现**，不参与当前项目构建
- 现状代码与当前 `services/`、`web/`、`web/admin/` 完全独立，**修改这里不会影响线上任何东西**
- 需要参考某个旧实现时直接看就行，不要 fork / 修改
- 真正要做实验请在 `services/` 或 `web/` 下开新分支

## 为什么保留

保留旧实现是为了：
1. 看到架构演进路径（怎么从单体 Spring Boot → 微服务 Go）
2. 偶尔抄一些工具函数（如分页、鉴权逻辑）
3. 对比新写代码与旧实现的优劣

## 不要做的事

- ❌ 在 `old/` 下加新文件
- ❌ 修改 `old/` 下任何 tracked 文件
- ❌ 把 `old/` 移到其他位置（破坏 git history 引用）
- ❌ 引用 `old/` 里的代码到当前项目（import path 会跨年失效）

## 如果你觉得旧实现没价值

PR 删整个 `old/` 即可。当前大小：17M（git 累计）/ 32M（工作区），主要是 .vue/.tsx/.go 源码，不是二进制。
